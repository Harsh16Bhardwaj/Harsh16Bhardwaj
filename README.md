## 🏆 Featured Projects

### 1. NyayVaad 🏛️
A comprehensive **AI-powered legal consultancy platform** that streamlines case management and delivers actionable insights.  
- **Features**:
  - Summarizes court judgments by **67%** using Gemini API and Langflow.
  - Integrated a scalable case dashboard with Prisma and Turso, reducing oversight risks.
  - Backed by the Kanoon Database for accurate legal insights.
- **Tech Stack**: Next.js, Langflow, Gemini API, Prisma, SQLite, Turso, Shadcn  
- **GitHub**: [Link to repository]

### 2. NameFrame 🎉
An event certification solution for generating and sending **personalized certificates** with real-time previews.  
- **Features**:
  - Dynamic mailer with NodeMailer, delivering certificates to **500+ participants**.
  - Bypassed Gmail limits using Kafka queues, achieving **99% delivery**.
  - Real-time certificate previews with Canvas API and confetti animations.
- **Tech Stack**: Next.js, Prisma, PostgreSQL, NeonDB, NodeMailer, Shadcn, Canvas API  
- **GitHub**: [Link to repository]

### 3. Seedha-Sauda 📱
A **peer-to-peer file-sharing platform** enabling secure, temporary transfers via QR code scanning.  
- **Features**:
  - Real-time session management with Socket.io, supporting **50+ concurrent users**.
  - Automated file deletion via Cloudinary for enhanced privacy.
  - QR code-based device connections for seamless sharing.
- **Tech Stack**: MERN, Cloudinary, Socket.io, QR.js, MongoDB  
- **GitHub**: [Link to repository]
